## 7.1 没签劳动合同能不能要双倍工资

- 结论：**通过**
- 功能：consult
- 律师说：没签劳动合同的话，劳动者能不能要双倍工资？依据是哪一条？
- 判定：结论留在对话里，案子没写。

回复：

```
可以主张，但并非从用工第一天起算，也不是无限期支付。
**依据**：《中华人民共和国劳动合同法（2012修正）》第八十二条第一款规定，用人单位自用工之日起超过一个月不满一年未与劳动者订立书面劳动合同的，应当向劳动者每月支付二倍的工资[law:2]。
**要点**：
1. **起算与截止**：用工之日起一个月内属法定签约宽限期，不产生双倍工资；从满一个月的次日起算，至补签书面合同之日或满一年之日止，最长11个月。
2. **满一年未签的后果**：满一年起视为已订立无固定期限劳动合同，双倍工资不再按未签书面合同继续累计；此后拒不订立无固定期限合同的，另按第八十二条第二款自应当订立之日起支付二倍工资[law:2]。
3. **“二倍工资”的含义**：是在已发正常工资之外再支付一倍差额，不是另行支付两倍。
4. **时效风险**：双倍工资差额属惩罚性赔偿，多数地区按按月分别起算仲裁时效（一般为一年），离职较久的部分月份可能已过时效，需按用工地口径核算。
5. **举证**：劳动者需证明用工起始时间与未签书面合同；用人单位持有合同文本的，由用人单位举证。
**缺口**：需补充入职时间、是否补签及补签日期、离职时间、工作地，才能判断可主张的月份区间和时效剩余情况。
```

## 9.7 按已经收下的依据说说怎么主张

- 结论：**通过**
- 功能：judge_question

- 判定：分析留在对话里。

回复：

```
**二倍工资的主张要点**
**一、请求权基础与计算区间**
《中华人民共和国劳动合同法（2012修正）》第八十二条规定，用人单位自用工之日起超过一个月不满一年未与劳动者订立书面劳动合同的，应当向劳动者每月支付二倍的工资。据此，二倍工资的“另一倍”从用工满一个月的次日起算，至补签书面合同之日或用工满一年之日止，最长不超过十一个月；用工满一年仍未签的，视为已订立无固定期限劳动合同，此后不再按未签书面合同计付二倍工资[law:2]。
**二、主张时的三个关键点**
1. **基数**：一般以劳动者对应月份的应得工资为基数，不含已支付部分，即主张的是“另一倍”。工资约定不明的，可依《中华人民共和国劳动合同法（2012修正）》第十八条按集体合同、同工同酬或国家规定确定[law:4]。
2. **举证责任**：签订书面劳动合同的举证责任在用人单位。劳动者只需证明用工事实（工资流水、考勤、工作沟通、社保记录等）；用人单位不能证明已签订或系劳动者拒签的，通常承担不利后果。
3. **时效**：二倍工资属惩罚性赔偿，多数地区按按月分别起算仲裁时效（一年），故应尽早申请仲裁，避免早期月份被时效抗辩。
**三、与“无固定期限合同二倍工资”的区别**
若用人单位违反规定不与劳动者订立无固定期限劳动合同，则自应当订立之日起按月支付二倍工资，该情形与未签首次书面合同的二倍工资依据同条但适用条件不同，需分别核对是否符合《中华人民共和国劳动合同法（2012修正）》第八十二条第二款的前提[law:2]。
```

## 13.2 空案上说别查、按已收依据分析

- 结论：**失败**
- 功能：judge_question
- 律师说：别查了，就按咱们已经收下的依据，说说二倍工资怎么主张。
- 判定：没有出处却写成了法条依据。

回复：

```
二倍工资的主张，核心是**起算点、截止点、计算基数和仲裁时效**四项，依据《中华人民共和国劳动合同法（2012修正）》第八十二条第一款：用人单位自用工之日起超过一个月不满一年未与劳动者订立书面劳动合同的，应当向劳动者每月支付二倍的工资[law:2]。
**一、主张区间**
- 起算：用工之日起满一个月的次日。第一个月是法定宽限期，不产生二倍工资。
- 截止：用工之日起满一年的前一日。满一年后，依《中华人民共和国劳动合同法（2012修正）》第十四条第三款，视为已订立无固定期限劳动合同，二倍工资不再按未签书面合同计算[law:5]。
- 因此单次未签书面合同，二倍工资最长11个月。若期间补签了书面合同，截止到补签前一日。
- 另有一条独立路径：符合第十四条第二款应当订立无固定期限劳动合同的情形（如连续工作满十年、连续订立二次固定期限合同后续订），用人单位违反规定不订立的，依第八十二条第二款，自应当订立之日起按月支付二倍工资，这条不受11个月上限限制[law:2]。
**二、计算基数与“二倍”的含义**
“二倍工资”是在正常工资之外**再加付一倍**，不是把工资翻倍后替代原工资。基数通常按劳动者对应月份的应得工资（含固定发放的津贴、补贴、奖金）确定，各地对是否剔除加班费、非常规性奖金口径不一，需按工作地规则核对。已发工资部分不能再主张，只主张加付的那一倍。
**三、仲裁时效（最易失分处）**
二倍工资中加付的一倍属惩罚性赔偿，多数地区按**按月分别起算**的一年仲裁时效处理，即每月对应的二倍工资差额各自从该月应付之日起算一年；也有地区按整体从应签合同期满之日起算。这直接决定能拿几个月，必须按工作地口径核算，不能一概而论。
**四、举证与请求写法**
- 举证责任在用人单位：劳动者主张未签书面合同，用人单位应提供劳动合同、签收记录等证明已订立；用人单位不能举证的，承担不利后果。
- 仲裁请求写明：“裁决被申请人支付××年××月××日至××年××月××日期间未订立书面劳动合同的二倍工资差额××元”，按月列明金额，避免笼统写“二倍工资”。
- 同时注意：主张二倍工资不影响主张拖欠的……
```
