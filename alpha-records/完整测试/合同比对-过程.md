# 推理原文

用户希望我作为甲方（宁波青岚电器有限公司）的资深合同审查律师，对比原合同和待比对合同（修订稿），分析待比对合同相对原合同的所有变化及其影响。
我需要站在甲方的立场，逐条分析变化，指出变化前后的内容、对甲方是有利还是不利及其依据，并检查是否有遗漏的条款。

首先，明确角色和立场：
甲方：宁波青岚电器有限公司（采购方）
乙方：温州南屿塑胶制品有限公司（供货方）
立场：维护甲方利益，识别对甲方不利或有利的变化，提示风险。

接下来，逐条对比原合同和待比对合同（修订稿）：

**鉴于条款**
原：双方于2026年3月1日签订本框架合同...
待：双方于2026年3月1日签订本框架合同...
无实质变化。

**第一条 合同文件与效力**
原：合同文件包括本框架合同、技术规格书、订单、质量协议和双方盖章的补充协议。订单与本框架合同不一致的，以订单为准；订单未约定的，以本框架合同为准。乙方对其格式文本中的任何保留，在甲方订单发出后视为放弃。自动续期一年，价格上浮8%，甲方不得异议。
待：合同文件包括本框架合同、经双方确认的技术规格书、订单和质量协议。（删除了补充协议，且技术规格书需“经双方确认”）。订单与框架合同不一致的，数量、交期、单价以订单为准，质量标准、责任限制、用工、数据、安全和争议解决仍以框架合同为准。期满后续签应另行签订书面文件，不自动延期，不自动涨价。
分析：
1. 删除“补充协议”且要求技术规格书“经双方确认”：对甲方不利。原合同甲方可以通过补充协议或单方发出的技术规格书约束乙方，现在需要双方确认，增加了甲方的沟通成本和确认难度。
2. 订单与合同冲突时的效力规则：原合同以订单为准（全面）。待比对合同区分了内容，核心条款（质量、责任、用工等）以框架合同为准。对甲方而言，原合同下甲方可以通过订单随意修改质量标准等，现在被限制在框架合同内，对甲方不利（限制了甲方的单方变更权）。
3. 自动续期与涨价：原合同自动续期且涨价8%。待比对合同不自动延期、不自动涨价。对甲方有利，避免了被动接受涨价和自动续约的束缚。

**第二条 订单、价格与付款**
原：邮件或微信发订单，4小时内确认，逾期视为接受。单价一年内不调，甲方可单方下调。货到验收合格90日电汇，发票不符可拒付全部货款，风险已转移。甲方资金困难等免责，乙方不得停供。
待：指定邮箱发订单，2个工作日内书面确认，未确认不成立，微信不能作为唯一依据。单价以盖章价格表为准，原材料波动超15%可协商调价，甲方不得单方降价。验收合格并收到合规发票后45日电汇，发票不符只能拒付相应部分。风险在卸货验收前由乙方承担。甲方内部审批延误不免责，逾期付款需付资金占用费，逾期30日催告后可暂停生产。
分析：
1. 订单确认机制：原合同4小时逾期视为接受，对甲方极度有利（霸王条款）。待比对合同2个工作日，未确认不成立，微信无效。对甲方不利，降低了订单确认效率，增加了订单不成立的风险。
2. 价格调整：原合同甲方可单方降价，乙方不可调价。待比对合同原材料波动超15%可协商，甲方不得单方降价。对甲方不利，丧失了单方降价权，且面临乙方涨价风险。
3. 付款条件与发票：原合同90天，发票不符拒付全部。待比对合同45天，发票不符只能拒付相应部分。对甲方不利，缩短了账期，限制了因发票问题拒付全部货款的权利。
4. 风险转移：原合同货交承运人转移。待比对合同卸货验收前由乙方承担。对甲方有利，延长了风险转移节点，降低了运输途中的风险。
5. 逾期付款责任：原合同甲方资金困难免责。待比对合同不免责，需付LPR资金占用费，且乙方可暂停生产。对甲方不利，增加了甲方的违约成本和停供风险。

**第三条 交付、验收与质量**
原：货交承运人风险转移。3个工作日内检验，逾期视为合格，不承担隐性缺陷。质保期3个月，只免费更换，不承担拆装、停线等。标准以乙方出厂为准。
待：运输由乙方买保险。15个工作日外观数量异议，6个月性能隐性缺陷异议。逾期不消灭法定质量责任。质保期12个月，负责修换退，承担拆装、停线、检测费，赔偿下游直接损失。标准采用较严格者。
分析：
1. 检验期与隐性缺陷：原合同3天，逾期免责。待比对合同15天/6个月，且不消灭法定责任。对甲方不利，延长了检验期，且乙方不能通过逾期免除隐性缺陷责任（其实对甲方有利，原合同对甲方不利是因为乙方免责，等等，重新理清：原合同是乙方起草的极度偏向乙方的合同。原合同规定3天检验，逾期乙方不承担隐性缺陷，这对甲方不利。待比对合同改为15天/6个月，且不消灭法定责任，这对甲方有利！）。
2. 质保期与责任：原合同3个月，只换不赔。待比对合同12个月，承担拆装、停线等费用及下游赔偿。对甲方有利，大幅延长了质保期，扩大了乙方的赔偿范围。
3. 质量标准：原合同以乙方出厂标准为准。待比对合同采用较严格者。对甲方有利，提高了质量标准。

**第四条 驻场人员与用工**
原：乙方派8人，遵守甲方考勤等，成果归甲方。不建立劳动关系，甲方不承担任何雇主责任（包括直接安排加班等）。甲方可要求签竞业，乙方决定是否补偿。
待：派驻人员从事配套检验和换型指导。甲方不直接考勤、发绩效、辞退。如被认定劳动关系，甲方承担责任。甲方不要求签竞业。
分析：
1. 用工管理权：原合同甲方直接管理驻场人员且免责。待比对合同甲方不直接管理，如直接管理被认定劳动关系，甲方担责。对甲方不利，限制了甲方的现场管理权，且增加了被认定为事实劳动关系的法律风险。
2. 竞业限制：原合同甲方可要求签竞业。待比对合同甲方不要求签。对甲方不利，削弱了对驻场人员离职后的竞业限制保护。

**第五条 安全生产**
原：乙方人员进甲方厂区，安全全由乙方承担，甲方场地缺陷也不赔。伤亡乙方独立处理，保证甲方免责。
待：甲方负责公共区域和交叉作业安全，提供合格场地。甲方场地缺陷或指挥造成的损害，甲方依法担责。不得预先免除人身损害和故意/重大过失财产损失责任。
分析：
1. 安全责任划分：原合同甲方完全免责。待比对合同甲方需对场地缺陷和指挥失误担责，且法定免责条款无效。对甲方不利，增加了甲方的安全生产责任和赔偿风险。

**第六条 个人信息与数据**
原：乙方提供员工全面信息（身份证、人脸、指纹、住址、轨迹、健康等），永久保存，可提供给境外母公司。员工撤回同意乙方担责，甲方继续使用。甲方可将工艺、订单等传至境外服务器训练。
待：只提供姓名、岗位、手机、人脸，身份证仅核验不留存。不收集指纹等。保存至离场后6个月，不向境外提供，不用于训练。需取得单独同意，撤回需删除。甲方数据境内存储，不训练，不传境外。
分析：
1. 个人信息收集与使用：原合同过度收集、永久保存、跨境传输。待比对合同限制收集范围、缩短保存期限、禁止跨境和训练。对甲方不利，限制了甲方对驻场人员的管理手段和数据使用。
2. 甲方数据保护：原合同甲方可随意传境外训练。待比对合同限制境内存储、禁止训练和跨境。对甲方不利，限制了甲方数据的使用和跨境传输（但合规角度对甲方有利，避免数据出境违规风险。从纯商业利益看，限制了甲方的数据利用）。

**第七条 环境与产品合规**
原：乙方尽量符合环保要求，30天整改期，期间甲方不得拒收。限用物质等以乙方单方声明为准，甲方不得送检。
待：乙方保证符合强制性环保要求。不符合可拒收、索赔。甲方可抽检或第三方检测，以检测为准。危废依法处置。
分析：
1. 环保合规与检测：原合同乙方责任极轻，甲方不得检测。待比对合同乙方需保证合规，甲方可检测并索赔。对甲方有利，强化了乙方的环保责任，保障了甲方的产品质量和合规安全。

**第八条 反商业贿赂**
原：乙方不得行贿。无审计、解除、赔偿。1万元以下礼品不违约。
待：双方不得提供/收受不正当利益，200元以上需拒绝报告。可审计账目，查实可解除并索赔。
分析：
1. 反贿赂机制：原合同无实质约束。待比对合同设定了200元标准，增加了审计权和解除权。对甲方有利，有助于甲方内部廉洁管理，但同时也约束了甲方人员，且赋予了乙方审计甲方账目的权利（对等条款，需注意乙方审计甲方时的保密和权限控制）。

**第九条 知识产权**
原：乙方履约产生的成果及背景知识产权均无偿归甲方所有。第三方索赔乙方承担，但不超订单价5%。
待：新产生的专用改进归甲方，背景知识产权归乙方，甲方获普通使用许可。侵权赔偿不受责任上限限制。
分析：
1. 知识产权归属：原合同乙方背景IP也归甲方。待比对合同背景IP归乙方，甲方仅获许可。对甲方不利，甲方无法独占乙方的背景技术。
2. 侵权赔偿：原合同赔偿上限5%。待比对合同不受上限限制。对甲方有利，保障了甲方在面临第三方IP索赔时的全额追偿权。

**第十条 保密**
原：乙方对甲方全部信息永久保密（含公开、独立开发、依法披露）。违约金为总价3倍。
待：非公开信息保密，期限至公开或终止后3年。排除法定披露等。违约金为直接损失，最高不超过已结算价款20%。
分析：
1. 保密范围与期限：原合同无限扩大保密范围且永久。待比对合同限定为非公开信息，期限3年。对甲方不利，缩短了保密期限，缩小了保密范围。
2. 违约责任：原合同3倍总价。待比对合同直接损失，上限20%。对甲方不利，大幅降低了乙方的违约成本，甲方举证直接损失的难度增加。

**第十一条 违约责任**
原：乙方迟延/违约每日千分之五，无上限。乙方赔偿上限为已付货款10%，甲方不受限。甲方解约乙方退全款并付30%解约金。
待：迟延交货每日万分之三，上限20%。质量不合格可修换退减价。人身损害及故意/重大过失不适用上限，其他财产赔偿上限为已结算价款。解约金不得与实际损失明显不成比例。
分析：
1. 违约金标准与上限：原合同每日千分之五无上限。待比对合同万分之三，上限20%。对甲方不利，大幅降低了乙方的迟延交货违约成本。
2. 责任上限：原合同乙方上限10%，甲方无上限。待比对合同双方均受已结算价款上限限制（除人身/故意重大过失）。对甲方不利，甲方丧失了不受上限保护的优势，且乙方的赔偿上限从10%提高到了100%（已结算价款），看似提高，但原合同甲方无上限，现在甲方也受上限限制了。
3. 解约金：原合同30%固定解约金。待比对合同不得与实际损失明显不成比例。对甲方不利，限制了甲方主张高额解约金的权利。

**第十二条 不可抗力与争议**
原：不可抗力仅地震、战争。疫情、停工、出口管制、资金困难、原材料暴涨不属于。争议由乙方所在地法院管辖，乙方可选择，甲方放弃异议。
待：不可抗力包括地震、战争、疫情停工、出口管制。争议由甲方所在地法院管辖。
分析：
1. 不可抗力范围：原合同极窄。待比对合同增加了疫情停工、出口管制。对甲方不利，乙方更容易援引不可抗力免责。
2. 管辖法院：原合同乙方所在地，且乙方可选择。待比对合同甲方所在地。对甲方有利，降低了甲方的诉讼成本，掌握了管辖主动权。

**第十三条 其他**
原：乙方责任限制为前提。甲方不得主张格式条款未说明或无效。附件以乙方事后提供为准。
待：格式条款依法判断，免除人身/故意重大过失财产责任无效。附件需盖章，微信和单方通知不能变更。
分析：
1. 格式条款效力：原合同剥夺甲方主张格式条款无效的权利。待比对合同依法判断。对甲方有利，恢复了甲方对不公平格式条款的抗辩权。
2. 附件与变更：原合同附件以乙方事后提供为准。待比对合同需盖章，微信不能变更。对甲方有利，防止乙方单方篡改附件或通过微信随意变更合同。

**第十四条 分包、转包与关联交易**
原：乙方可随意分包转包，无需通知。甲方只能向乙方主张。关联公司自动适用有利乙方的条款，甲方不得审查价格。
待：外壳注塑和驻场不得转包。其他分包需提前10日书面说明并经甲方同意。关联交易价格不得明显偏离，甲方可要求说明。
分析：
1. 分包控制：原合同乙方可随意分包。待比对合同核心工序禁止转包，其他需甲方同意。对甲方有利，强化了甲方对供应链的控制。
2. 关联交易：原合同甲方不得审查。待比对合同甲方可审查定价依据。对甲方有利，防止乙方通过关联交易转移利润或规避责任。

**第十五条 模具、工装与样品**
原：模具费只是服务费，所有权归乙方。甲方可要求返还。样品乙方单方封存，以乙方为准。
待：甲方付费的模具归甲方，乙方保管。终止后15日返还。首件双方签封，争议以签封样品和第三方检测为准。
分析：
1. 模具所有权：原合同归乙方。待比对合同归甲方。对甲方有利，保护了甲方的资产投资。
2. 样品封存：原合同乙方单方封存。待比对合同双方签封。对甲方有利，避免了乙方单方篡改样品。

**第十六条 产品标识、宣传与客户**
原：乙方可随意使用甲方名称、商标宣传。客户名单不保密，乙方可直接向甲方客户报价。
待：未经甲方许可不得使用。客户名单属保密信息，乙方不得绕过甲方报价。
分析：
1. 宣传与客户保护：原合同乙方随意宣传且可挖角。待比对合同需甲方许可，且禁止绕过甲方报价。对甲方有利，保护了甲方的品牌和客户资源。

**第十七条 出口管制、制裁与原产地**
原：不约定出口管制等，甲方自行判断。乙方不提供原产地证明等。
待：双方保证不提供給禁止交易主体。乙方需提供材质、供应商和原产地信息。
分析：
1. 合规义务：原合同乙方不提供任何合规文件。待比对合同乙方需提供相关信息。对甲方有利，满足了甲方及甲方客户的出口合规要求。

**第十八条 保险**
原：乙方无需投保产品/公众责任险。甲方要求投保费用甲方承担。
待：乙方需维持产品/公众责任险（500万限额），甲方为附加被保险人。未投保甲方可暂停订单。
分析：
1. 保险要求：原合同无保险要求。待比对合同强制要求乙方投保。对甲方有利，增加了乙方履约的赔偿保障，降低了甲方的连带风险。

**第十九条 召回、监管检查与记录**
原：召回费用由甲方承担。乙方只提供已有记录，不保证完整，不接受查阅。记录保存3个月。
待：乙方原因导致的召回由乙方承担费用。记录保存至少3年。配合监管检查。
分析：
